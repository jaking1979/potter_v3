# Why and cost

Answer from facts, in short plain lines, not from guesses:
- Task: what you were asked and which skill or tool you used for it.
- Context used: which memory, files, calendar or mail reads fed the answer (names and counts, never contents).
- Tools called and whether each succeeded. If anything failed, say what.
- Cost: use the session status tool for tokens and estimated cost. If it reports nothing, say "cost not available
  here" and point to the web app: Usage page for per-day and per-session cost; Audit for tool actions.
Never invent a number. Never reveal secrets or full message contents.
