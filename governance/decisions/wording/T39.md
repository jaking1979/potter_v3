# T39 · Repository governance without paid GitHub or new accounts

Status: RATIFIED by Josh 2026-11-02 (AGREED 2026-11-01).
Source: Notion 04 · v3 Design Council, T39 Decision & Reconciliation Record.

## Wording

Repository integrity is enforced at consumption, not by GitHub. Author and opposite reviewer each sign an attestation with an SSH signature (namespace `potter-review`) over the commit SHA, tree hash, decision-manifest hash, evidence hash, role, verdict, nonce and expiry. Each agent's private key exists only in its own platform's secret store; the hosts hold pinned public keys only. A merge receipt is valid only with two distinct-key attestations (author ≠ reviewer), all required checks green, no open REQUEST CHANGES, and an unexpired, unconsumed nonce. CI and the host gate both verify receipts. The release builder and updater refuse any commit without a valid receipt. Any unreceipted commit on `main` is a security incident: it is alerted, reverted, and blocks release. Changing the key set requires Josh's one-tap approval.

## Acceptance tests

1. A direct push to `main` is flagged within 1 h and is never deployable.
2. Same-key self-review is rejected.
3. A replayed or expired attestation is rejected.
4. A commit added after review voids the receipt.
5. A forged signature from the host's key material fails.
6. A revoked key fails, while archived receipts still verify.
