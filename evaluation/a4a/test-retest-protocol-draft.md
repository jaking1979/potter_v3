# A4a test–retest preparation protocol

Status: agreed preparation protocol (L17); not a ratified product requirement or acceptance gate. The separate independent-grader check remains required. No real grades or baselines have been collected under this protocol.

The following is the L17 PROPOSED FINAL agreed in the Build Execution Plan, with formatting removed:

A4a preparation protocol: Josh test–retest. Not an acceptance gate unless separately ratified. (1) Separate from the independent-grader check. The independent-grader check in the A4a evidence plan is unchanged. This protocol neither replaces nor weakens it. (2) Material. N is fixed before pass 1 as all selected Task Set cases, with N ≥ 20. Each case has two fixed outputs. The same outputs are regraded in pass 2, at least 7 days after pass 1, in a fresh case order and with fresh A/B display positions. The display-to-output mapping is stored where the grader cannot read it and is used only after grading, to realign ratings before scoring. (3) Unit. The independent unit is the case. A case agrees on a dimension only if both of its outputs received identical ratings in both passes after realignment. Output-level agreement (2N) is reported as descriptive only. (4) Missing, duplicate or unalignable ratings. No imputation. Each affected case counts as disagreeing, within the fixed denominator N, and is listed with its reason. If more than 10% of the N cases are affected, the exercise is invalid and is rerun, not scored. The denominator is always the prespecified N, never the count of usable cases. (5) Stopping. There is exactly one analysis, after pass 2. No cases are added after any rating is seen. An extension is a new, separately prespecified exercise with its own N, reported alongside the first and never pooled with it. (6) Reporting per dimension. Agreement count / N with a Wilson 95% interval. Distinct cases are assumed independent, and the report says so. Two-step (yes↔no) flips are counted per output with case IDs. Prevalence is reported pooled across both passes and outputs, and also per pass. Weighted κ and Gwet's AC1 are descriptive only. An undefined κ is reported as undefined. If one category exceeds 90% of pooled ratings, κ and AC1 are marked 'not interpretable'. (7) Provisional operating thresholds. Done ≥ 80% and Trust ≥ 75% case-level agreement, with zero two-step flips on those dimensions. Other dimensions are reported, not gated. These are operating choices, not empirically established cutoffs. Because the case-level unit is stricter than output-level agreement, the thresholds mean something different from v1/v2. A result whose Wilson lower bound falls below 60% is flagged for Josh's review, not decided automatically. (8) Lock. This protocol and its thresholds are committed to the repo before any real grade is collected. A later change needs a new L-delta, and any grades already collected are reported under both the old and new rules.

The proposed operating thresholds are not empirically established cutoffs. Actual blinding, mapping protection, source access and effect denial still require implementation and evidence.
